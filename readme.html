Portfolio — Setup & Workflow Guide

How to connect GitHub, Vercel, and VS Code — and the best workflow for editing this website.

What you have

This is a static website — HTML, CSS, and JavaScript only. No build step is required. Vercel serves the files as-is, which makes updates fast and simple.

One-time setup

1. Install tools

  • VS Code — for editing files
  • Git — for version control (includes Git Bash on Windows)
  • Node.js (optional) — only needed if you want a local preview server via npx serve

2. Create a GitHub repository

  1. Sign in at github.com
  2. Click New repository
  3. Name it e.g. portfolio-2026
  4. Leave it empty — do not add README or .gitignore yet
  5. Copy the repository URL (e.g. https://github.com/yourname/portfolio-2026.git)

3. Push your project to GitHub

Open a terminal in your project folder and run:

cd "e:\Valtech\Web Projects\Protfolio-2026"

git init
git add .
git commit -m "Initial portfolio setup"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/portfolio-2026.git
git push -u origin main

Replace YOUR_USERNAME with your GitHub username.

4. Connect Vercel

  1. Sign up at vercel.com using your GitHub account
  2. Click Add New → Project
  3. Import your portfolio-2026 repository
  4. Use these settings:
Framework Preset Other
Build Command Leave empty
Output Directory . (root)
Install Command Leave empty
  1. Click Deploy
  2. You will get a live URL like portfolio-2026.vercel.app
Custom domain: In Vercel → Project → Settings → Domains, add your own domain and follow the DNS instructions.

5. Open the project in VS Code

  1. Open VS Code
  2. File → Open Folder
  3. Select Protfolio-2026

Recommended VS Code extensions:

  • Live Server — preview changes in the browser while editing
  • Prettier — keeps HTML/CSS/JS formatted (optional)

Best workflow for editing

Edit in VS Code → Preview locally → Git commit → Git push → Vercel auto-deploys

Step 1 — Edit files

Most changes happen in these files:

js/config.js Your name, role, email, social links, marquee text, intro paragraph, version label
js/projects.js Full project case studies — text, images (.jpg, .png), videos (.mp4)
about.html About page body text
service.html Services list and descriptions
work.html Work page project cards and links
contact.html Contact page text
css/style.css Colors, fonts, spacing, layout
fonts/ Custom fonts (TheNightWatch, Inter)
images/projects/ Project images and videos (create this folder when needed)

Step 2 — Preview locally

Option A — Live Server (recommended)

  1. Install the Live Server extension in VS Code
  2. Right-click index.html → Open with Live Server
  3. Browser opens at http://127.0.0.1:5500 and refreshes on save

Option B — Python (if installed)

cd "e:\Valtech\Web Projects\Protfolio-2026"
python -m http.server 3456

Then open http://localhost:3456

Step 3 — Save and publish

When you are happy with your changes, push to GitHub. Vercel deploys automatically.

git add .
git commit -m "Update about page copy"
git push

Your live site updates in about 30–60 seconds. Check progress in the Vercel dashboard.

Adding a new project

  1. Add an entry in js/projects.js (copy an existing project block)
  2. Add a project card on work.html with link: project.html?p=your-slug
  3. Put media files in images/projects/your-slug/
  4. Reference paths in projects.js, e.g. "images/projects/your-slug/hero.mp4"
  5. Commit and push

Adding images & videos to a project

In js/projects.js:

heroImage: "images/projects/brand-identity/hero.mp4",
gallery: [
  "images/projects/brand-identity/screen-01.jpg",
  "images/projects/brand-identity/demo.mp4",
  "images/projects/brand-identity/screen-02.jpg",
],

Videos (.mp4, .webm, .mov) autoplay muted with no player controls. Leave paths as "" to show a white placeholder until files are ready.

Tips for a smooth workflow

  • Commit often — small commits with clear messages (e.g. Update work page projects) are easier to track
  • Preview before pushing — always check locally with Live Server first
  • Use branches for big changes — create a branch in GitHub/VS Code, merge when ready; Vercel gives each branch a preview URL
  • Never commit secrets — no passwords or API keys in your files; this site does not need a .env file
  • VS Code Source Control — click the branch icon in the left sidebar to commit and push without using the terminal

Quick reference — Git commands

git status See what files changed
git add . Stage all changes for commit
git commit -m "message" Save a snapshot locally
git push Upload to GitHub → triggers Vercel deploy
git pull Download latest from GitHub (if editing on another machine)

Troubleshooting

Site not updating after push Check Vercel dashboard for deploy status; confirm you pushed to main
Changes look wrong locally Hard refresh browser: Ctrl + Shift + R
Git push rejected Run git pull first, resolve conflicts, then push again
Images not showing live Check file path in projects.js matches the folder; ensure files were committed and pushed
